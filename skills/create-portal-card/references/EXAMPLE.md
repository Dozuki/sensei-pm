# AI Generated Release Notes

# Overview
Release Notes AI turns routine guide and procedure updates into clear, publish-ready summaries — automatically. Instead of someone manually writing up what changed, the Assistant drafts it for you, so every update gets communicated fast and consistently.

# How it Works
1. When a guide, work instruction, or procedure is revised, the Assistant detects the change.
2. It drafts a plain-language summary covering what changed, why it matters, and who's impacted.
3. Content owners review, tweak if needed, and publish — with the note automatically tied to the guide's version history.

# Who's it For
- Content owners and authors managing frequent guide revisions
- Operators and technicians who need a heads-up before their next task changes underneath them
- Quality and compliance teams tracking a clean audit trail of changes over time
