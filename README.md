# 🧙Sensei
## Dozuki's Claude Skills toolkit for Product Management

A growing library of reusable Claude skills that turn PM busywork—customer insight clustering, spec drafting, competitive briefs—into repeatable, one-command workflows. Built by the Dozuki PM team, for the Dozuki PM team.

## What are Skills?

Skills are markdown files that give AI agents specialized knowledge and workflows. Add them to your project and Claude Code (or any agent that reads `SKILL.md` files) applies the right frameworks when you work on a matching task.
